# 疯狂星期四：V我50

一个纯 HTML / CSS / JavaScript 的「群友 V50 对决」卡牌对战小游戏。玩法参考《植物大战僵尸：英雄》：
**5 条战线、能量出牌、双方随从同一阶段对撞、关键词、英雄技能斩杀**，外加一张**杀戮尖塔式随机地图**的肉鸽冒险。
全部美术用 emoji，零依赖、零构建、零联网，电脑和手机都能玩。

> 今天星期四，群友集体装死。打一场，谁赢谁请客。
>

## 运行

双击 `index.html` 即可（Chrome / Edge / Firefox / 手机浏览器）。
不需要服务器、npm、任何第三方库。

```
crazy-thursday/
├── index.html   页面结构（菜单 / 卡组 / 商店 / 战斗 / 冒险地图 / 弹窗）
├── style.css    全部样式（桌面 + 移动端竖屏）
├── app.js       公共层：DOM 工具、音效、Toast、页面切换
├── data.js      85 张可收集卡 / 24 个敌人 / 地图与事件配置
├── store.js     存档、经济、卡池、卡组校验、地图生成与冒险进度
├── screens.js   菜单、对手、地图、事件、商店、奖励、卡组编辑
└── battle.js    战斗引擎、关键词、弃牌、AI、结算
```

存档在 `localStorage`（键名 `v50.profile.v5`）。「玩法说明 → 重置存档」可重来。

## 这轮新增

### 1. 杀戮尖塔式随机地图

「开始冒险」不再是线性六关，而是一张**每次重新生成的 8 行分支地图**：

- 起点 → 6 层随机节点 → BOSS，每层 2-4 个节点，节点之间有连线，只能沿着线往下走。
- 节点类型：⚔️ 战斗、💀 精英、❓ 事件、🛒 商店、💤 休息、👑 BOSS。
- 类型按层权重随机：前期只有战斗，中期开始出现精英 / 商店 / 事件，第 6 层保证至少一个休息点。
- 每层按难度抽敌人：1-2 层简单池、3-4 层普通池、5-6 层困难池；精英跳一档，BOSS 固定「疯狂星期四之神」。
- **血量继承**：每场战斗后回 4 点，休息点回 30%，一路打到 BOSS。
- **敌人血量会按节点打折**：普通战 ×0.72、精英 ×0.85、BOSS ×0.9（因为双方随从同时开打，硬拼更容易掉血）。
- **牌库成长**：这场冒险有独立牌库（初始=你编辑的 20 张），战斗胜利三选一、事件、商店都能往里加卡，越滚越大。
- 通关奖励 300 + 200 疯狂币。

节点效果：
- **休息**：回 30% 最大生命，或直接赶路。
- **事件**：5 个随机事件，各有 2 个选项（抢红包、神秘链接、深夜外卖、群友求助、广告轰炸）。
- **商店**：3 张随机卡按稀有度标价（60 / 110 / 190 / 320），买下直接进当前冒险牌库。

## 星期四彩蛋

主菜单会读系统日期：**只有星期四**才出现金色徽章「🗓 今天真的是星期四」，并在进入菜单约 1 秒后撒下炸鸡雨，弹出一张金色卡片：

- 文案是一段群聊小剧场（24 个人在线，没有一个人说话）；
- 点「V 我 50」可以领 **+50 疯狂币**，每个星期四只能领一次（按本地日期存在 `localStorage` 的 `v50.thursday.claim`）；
- 领过之后再打开，按钮会变成「今天已经 V 到了 ✓」，第二天（星期五）恢复成普通菜单，徽章与卡片都不再出现。

> 想手动看效果可以在控制台执行 `Screens.openThursdayEgg(true)`。

## 玩法速览

**一个回合的固定顺序：我方出牌 → 敌方出牌 → 双方随从攻击 → 判定随从死亡 → 下一回合。**

- 我方回合内随便出牌、用英雄技能、贴盾、回费；点「结束回合」进入结算。
- 结算时先由对手出牌（下随从、放法术、用技能），然后**双方随从在同一阶段一起开打**：
  同一条战线上的两个随从互相对撞，没人拦路的那一侧直接打英雄。
- 所有伤害算完后才统一判定死亡，所以 2/2 撞 2/2 是两边一起碎，不存在先手。
- 每回合开始抽 **1 张**牌（双方一样），手牌上限 10。
- 能量每回合回满：第 1 回合 2 点，之后每回合 +1，上限 10。
- 英雄技能「V我50」：2 能量打 3 点，每回合一次。
- 点场上随从看状态；点手牌再点空战线召唤；法术选中后点战场生效。
- 手牌上限 10，超过时结束回合要弃到 10 张。

## 关键词

| 关键词 | 效果 |
| --- | --- |
| 🛡 护甲 X | 受到伤害 -X |
| ➤ 穿透 | 攻击随从时同时命中敌方英雄 |
| ☠ 致命 | 被它伤害的随从直接倒下 |
| ✷ 溅射 X | 攻击时对相邻战线敌方随从造成 X |
| ♻ 转世 | 倒下时原地召唤召唤物 |
| 🎯 抗英雄 X | 攻击敌方英雄时 +X |
| 🔰 护盾 X | 抵消接下来 X 次伤害（英雄护盾则是抵消 X 点伤害） |
| 🩸 吸血 | 造成伤害时，为己方英雄回复等量生命 |
| ⚰️ 亡语 | 倒下时触发一次效果（如回复生命） |

## 改数据

卡牌在 `data.js` 的 `CARD_DEFS`：

```js
myCard: {
  name: '群友的假笑', emoji: '🙂', cost: 2,
  type: 'minion', atk: 3, hp: 2,
  rarity: 'rare', faction: 'kfc',
  role: '站场 / 抢节奏',
  armor: 1, pierce: true,          // 关键词
  text: '“哈哈，好啊。”',
  effect: { type: 'battlecryDamageHero', value: 1 }
}
```

敌人：`OPPONENTS`（tier 1-3）+ `ENEMY_DECKS`。

事件：`EVENTS`（标题、描述、两个选项与效果）。

## 修复记录（v5.1）

- **地图盖住事件弹窗**：`.modal` 的 `z-index` 由 60 提到 95，永远压在地图（75）/奖励（78）/结算（80）/开包（90）之上。弹窗带 `lock` 时右上角 ✕ 隐藏、点背景也不会关，必须先做选择。
- **事件结算后地图不回来 / 软锁**：休息、事件、商店结算后统一调用 `openRun()` 重新打开地图，而不是只重绘内容。
- **点弹窗内部按钮会顺手关掉弹窗**：根因是 `ev.target.closest('#modal')` 把面板内部的点击也算成「点背景」，改成只判断 `ev.target.id === 'modal'`。
- **跳过冒险奖励后软锁**：旧的「跳过」按钮还引用着已被删除的 `Store.runOpponent()`，会直接抛错导致地图不打开；现在统一回地图。
- **结算完成后无法回主菜单**：`☰` / `↻` 的忙碌守卫放宽为 `busy && !over`，任何已经分出胜负的状态都能退出。
- **进战斗节点改为「战斗成功开启后再收起地图」**，避免开局校验失败时停在一个空状态。
